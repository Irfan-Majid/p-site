IMAGES USED ON THE PUBLIC WEBSITE
=================================

Only pictures that the live site shows.
Admin address: admin.php


1. ADMIN CAN CHANGE THESE
-------------------------
Login, then use the menu. Uploading a new file there changes the site.
Allowed types: jpg, jpeg, gif, png. Max size: 5 MB.

HEADER LOGO (top of every page)
  What: the wide logo bar
  Admin: Banner Management -> Banner
  Edit record id 20, title "Logo"
  Link: admin.php?r=banner/update&id=20
  Size: about 1260 x 115 px
  Saved in: uploads/banner/
  The page always loads banner 20. A new banner does not replace it.

HOMEPAGE SLIDER PHOTOS
  What: the sliding photos on the home page
  Admin: Banner Management -> Banner
  Category: Slider banner
  Saved in: uploads/banner/

UNITS PHOTOS
  What: the units strip on the home page
  Admin: Banner Management -> Banner
  Category: Units
  Saved in: uploads/banner/

GALLERY PHOTOS
  What: gallery list and gallery detail pages
  Admin: Banner Management -> Banner
  Saved in: uploads/banner/

SUPERINTENDENT PHOTO
  What: the SP photo on the home page (shown twice)
  Admin: Content Management -> Content
  Edit record id 2
  Link: admin.php?r=content/update&id=2
  Saved in: uploads/content/

HISTORY PHOTO
  What: the history section photo on the home page
  Admin: Content Management -> Content
  Edit record id 4
  Saved in: uploads/content/

RECENT ACTIVITY THUMBNAILS
  What: the four photos under the recent-activities heading
  Admin: Content Management -> Content
  Any Active content in category 3. The site shows the newest 4.
  Saved in: uploads/content/

ARTICLE PHOTO
  What: the photo on a content detail page
  Admin: Content Management -> Content
  Edit that article and change its image.
  Saved in: uploads/content/


2. STATIC — ADMIN CANNOT CHANGE THESE
-------------------------------------
These are written into the theme files. The admin panel has no screen for them.
To change one, replace the file on the server and keep the same file name,
or edit the PHP/CSS path.
